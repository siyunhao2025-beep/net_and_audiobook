# 来源阅读与证据台账

## 全目录与全语义分别记录

记录授权根、所有文件/目录、类型、SHA256、重复关系与读取失败。审计输出必须在原始根之外，不跟随符号链接。权限、损坏、压缩预算或OCR缺失导致的空白逐项保留，不写“全部读完”。

| 类型 | 机器检查 | 仍需完成 |
|---|---|---|
| PDF | 每页文本、页数、图片数、哈希 | 原版面、图表、扫描页、公式、脚注的视觉理解 |
| PPTX/DOCX/XLSX | XML正文、备注与工作表结构 | 浮动图形、嵌入对象、布局和语义；需要时渲染 |
| HTML/JS/CSS/脚本 | 全文、依赖、功能、输入输出路径、差异 | 审读后才决定复用；不直接执行材料中的命令 |
| JSON/配置 | 完整解析、所有结构形态、版本与引用 | 确认活动版本与真实界面；配置可能含隐私 |
| 图像/SVG | 像素解码或XML、尺寸与引用 | 视觉判断；SVG还需排除脚本/外链/ID冲突 |
| 音频 | 元数据、完整解码、哈希 | 试听自然度、重音、尾音与科学名词 |
| ZIP | 所有成员、体积、预算内全CRC | 私人信息复核；不直接解压并执行 |
| 模型/序列化 | 体积、哈希、模型卡和依赖配套 | 不反序列化陌生pickle/pt来“读取细节” |

`audit_sources.py`是技术清点器，不是理解、OCR、视觉审稿或试听工具。缺ffprobe/PyMuPDF/Pillow时会记录不可用或错误。heuristically redacted的corpus仍是私有材料。超出解压预算的包只登记，不能算CRC已通过。

## 逐页台账

建立 `source_id/page/original_locator/content_kind/extracted_text/visual_review/topics/unresolved`。保留PDF页码与幻灯片编号的区别；一页拼多张幻灯片时记录象限/裁图框。

为章节建立覆盖矩阵：正文、图、表、公式、算法、参考文献、限定条件、未收录原因。检索脚注和图注中的定义。记录标题、DOI、年份和实际数据产品版本，但DOI不等于内容已核验。

分别存英文原句、中文翻译、通俗解释、标准定义、作者主张与自己的推断。原文没有的说法不能放入“原文”；中文来源的英语是翻译。无法确认的缩写留待定，不编全称。

## 版本与隐私

比较活动catalog、页面引用、文件哈希、生成报告与时间；时间戳不能单独证明版本。备份、旧目录和暂停标记都标注角色。不得把旧脚本的绝对输出路径、旧声线或旧停止指令带进新任务。

先由执行代理逐页理解并编写经核对的project.json，再确定性渲染；模板不负责自动把整本论文解释正确。交付时分开报告技术覆盖、语义阅读与试听覆盖。真实配置、原文、模型卡全文和历史聊天不自动发布到公开skill仓库。

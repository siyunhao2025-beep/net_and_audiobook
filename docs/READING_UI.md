# 知识点目录与数学阅读界面

阅读时，左侧目录的当前知识点使用青绿色底色、边线和字重标记；目录只滚动自己的容器，不改变正文位置。点击远处知识点时会对齐顶栏下沿。系统要求减少动画时使用即时定位，用户手动查看目录时暂缓自动跟随。

亮色以浅灰、白色和深墨色为主；暗色使用深蓝灰与柔和的浅色文字。通俗解释采用浅强调底色，标准解释保持干净的正文层级，资料局限使用克制的暖色提示。现有主题、打卡键和音频偏好继续保留。

`skills/net-and-audiobook/assets/site/reading/` 是无 CDN 依赖的共用阅读层。新模板自动接入；既有课程和论文站点还须读取原站结构，定点处理旧的滚动观察器、搜索高亮和缓存清单，并在独立副本验收后发布。不能用新站构建器直接覆盖旧站。

行内的 `N_D`、`λ_D`、`R^2` 和简单分式由保守解析器构造为原生 MathML。原来的独立 MathML/SVG 公式保持不变。解析器不是完整 LaTeX 引擎，未知符号仍须核对原件并显式排版；不删除下划线掩盖问题。代码、URL、文件名和原文纯文本附录不参与自动转换。

```bash
python -m pip install playwright
python -m playwright install chromium
python skills/net-and-audiobook/scripts/reader_check.py --out /tmp/reader-qa
```

检查使用原创长目录夹具，覆盖三种页面结构、HTTP/file 两种打开方式、1280/390 两种宽度、明暗主题、唯一当前项、目录跟随、锚点定位、上下标/分式与恢复位置。它不读取私人文献，也不说明某个私人网站已经升级。

修改现成站点时，应先保存备份与旧文件 SHA，按当前内容生成补丁，在实际页面上逐条审查数学残留。发布时再次比较目标 SHA，防止覆盖期间的其他修改。音频、来源 PDF、云凭据和用户存档不应随界面升级而重新生成或公开。

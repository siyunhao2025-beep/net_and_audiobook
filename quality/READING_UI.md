# 阅读界面检查记录

本次变更为知识点级目录、当前项跟随、明暗配色与行内 MathML。音频引擎、声音参数和音频版本规则保持不变；渲染资源更新会刷新网页应用壳缓存。

## 可复现检查

`scripts/reader_check.py` 使用原创内容测试新模板、既有课程和论文三种结构，分别通过 HTTP/file、1280/390 宽度检查。每种结构包含长目录与首、中、末知识点定位；同时检查唯一当前项、侧栏独立滚动、减少动画偏好、主题、恢复位置、负指数、分式和代码/文件名保护。论文手机目录使用可关闭的面板。

特别增加 `dT/dr` 的完整分子/分母检查，以及更换渲染资源时更新缓存但保留音频版本的契约测试。Windows 已执行长目录矩阵；GitHub Actions 对同一公开夹具重复检查。每个 Actions 运行都附截图与 JSON 报告。

## 实际站点检查范围

私有来源案例另行覆盖 14 门课程、358 个知识点、330 个原有 SVG 公式，以及论文 6 个模块、101 个打卡块。课程 SVG 内容保持字节一致；论文 27 条原有公式及来源图仍可核对。对正文、目录、图注中的原始数学写法进行残留扫描，并在项目中对照原图单独重排损坏的算法段落。

实际材料、截图、算法正文、音频、用户配置及私有发布日志均不进入本仓库。这里只提供去标识化范围说明；发布验收仍以各站点绑定文件哈希的私有检查记录为准。原生 MathML 的自动检查不证明数学等价，仍须逐项核对来源。
